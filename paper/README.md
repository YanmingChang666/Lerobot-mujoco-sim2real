## 新增内容如何并入原稿

1. 摘要与引言：补充多机械臂软件适配与仿真书写范围，不把新增试验写成跨平台真机验证。
2. 方法部分：增加工具坐标系、笔画与工具旋转解耦、七轴连续逆解、五秒进场及受约束 MPC。
3. 实验设置：将原 SO-ARM101 扰动实验与新的 1500 序列、100 轮书写任务训练分开描述。
4. 结果部分：增加本补充的七组归档结果及图 1–4；保持配置标签，不能把非配对行用于控制器优劣比较。
5. 讨论与结论：说明理想重力补偿、无接触、局部训练覆盖、未启用 UKF/KESO、无新增硬件试验等边界。

## 原稿合并前需要核对的内容

以下问题来自对原稿文本和当前实现的对照，尚未对原稿的全部历史实验做重新审计：

- 原稿训练段写入了 H 的 L1 惩罚，但当前 `models/losses.py` 未将它加入总损失；历史实验是否启用，应查当时版本与日志。
- 标准 DBKN 使用固定状态投影；不能笼统写成所有非可逆网络都使用可训练重构解码器。
- 谱半径项是软惩罚，不是“特征值保证小于 0.99”的硬约束，更不构成整个受控双线性系统的稳定性证明。
- 原稿引用编号存在错位：其参考文献列表中 UKF 是 [8]、ADRC 是 [9]、MuJoCo 是 [10]、CasADi 是 [11]、笔画数据是 [12]；正文多处指向了其他编号。外部文献条目本身仍需投稿前核验。
- 原稿描述“0.263 → 0.0150”时同时写“约 56 倍”，两者算术不一致，该对数值的比值约为 17.53。应先确认正确比较条件，不直接沿用摘要中的倍数。
- 原稿的全轨迹范数与新增的每点位置 RMSE 定义不同，不能混表直接排序。
- “任意汉字”“任意机械臂”不由当前有限工作区和单字实验支持，应限定为通过可达性与覆盖检查的任务。
- UKF 在提升空间中的优先性、文献创新性以及硬件结论仍需独立文献与实验审核；本补充不新增这类主张。
